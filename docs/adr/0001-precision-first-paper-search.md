# Precision-First Paper Search with Bounded LLM Expansion

paper-hub 对六个来源统一采用“精度优先”的检索策略：LLM 扩展生成器使用 `deepseek-v4-flash-0731`，只根据用户输入提出有限的中英文查询意图词；来源原生搜索负责召回，确定性的相关性门槛和本地排序负责最终结果。精确短语/标题命中优先于标题全词、摘要和关键词命中，不用宽泛结果补足数量，也不使用 LLM 或向量进行结果重排。模型输出必须经过结构、数量和内容边界校验，不能直接授予结果准入权；凭证只通过受保护的运行时环境层提供，不进入仓库、构建产物或 issue。这样可以避免把来源 API 的宽泛命中误呈现为相关论文，并让结果质量可解释、可测试；代价是增加模型调用失败和提示维护成本，稳定评测必须冻结扩展结果。
